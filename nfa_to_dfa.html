>_ 01 — FINITE AUTOMATA

THE NFA
DEFINED.

A 5-tuple (Q, Σ, δ, q₀, F). States. Alphabet. A transition function that maps to a set of states. Multiple paths. Infinite possibility. One input — many fates.

FORMAL DEFINITION
M = (Q, Σ, δ, q₀, F)
Q — finite set of states
Σ — finite input alphabet
δ — transition function
q₀ — start state ∈ Q
F — accept states ⊆ Q

>_ 02 — TRANSITION FUNCTION

δ : Q × Σ
→ 2Q

The NFA transition function maps each state-symbol pair to a power set of states. Every subset becomes a new DFA state. This is the insight that makes conversion possible.

NFA vs DFA DELTA
NFA: δ(q,a) → 2Q
DFA: δ(q,a) → Q
The NFA allows transitions to any subset of states. The DFA requires exactly one destination. Subset construction bridges this gap.

>_ 03 — EPSILON CLOSURE

THE SILENT
MOVE.

ε-transitions consume no input symbol. The ε-closure of a state is all states reachable via ε alone. Before each DFA move, we compute this closure — it's the foundation of correct conversion.

ε-CLOSURE ALGORITHM
ε-closure(q) =
{q} ∪ ε-closure(δ(q,ε))
Recursively follow all ε-edges. The resulting set forms the basis for DFA start state computation. Without this, the construction is incomplete.

>_ 04 — SUBSET CONSTRUCTION

POWERSET
METHOD.

Each DFA state is a set of NFA states. If the NFA has n states, the DFA has at most 2ⁿ states. Start from ε-closure(q₀). For each new state and symbol, compute transitions. Repeat until stable.

CONSTRUCTION STEPS
1. Start: ε-closure({q₀})
2. For each DFA state S, symbol a:
   move(S,a) = ∪ δ(q,a) ∀q∈S
3. New state = ε-closure(move(S,a))
4. Mark accepting if S∩F ≠ ∅
5. Repeat until no new states

>_ 05 — EQUIVALENCE THEOREM

LANGUAGE
EQUIVALENCE.

The DFA produced by subset construction recognises exactly the same language as the original NFA. L(NFA) = L(DFA). Determinism costs states — never expressiveness. This is the Rabin-Scott theorem (1959).

RABIN-SCOTT THEOREM
L(NFA) = L(DFA)
For every NFA N, there exists a DFA D such that L(N) = L(D). Proved by Michael Rabin and Dana Scott in 1959, earning them the Turing Award. The subset construction is the constructive proof.

>_ 06 — REGULAR LANGUAGES

CLOSURE
PROPERTIES.

Regular languages are closed under union, concatenation, Kleene star, complement, and intersection. The ability to convert NFA→DFA is what makes complementation and intersection decidable. DFAs make proofs constructive.

CLOSURE OPERATIONS
L₁ ∪ L₂ — Union
L₁ · L₂ — Concatenation
L* — Kleene Star
L̄ — Complement (needs DFA)
L₁ ∩ L₂ — Intersection
All preserve regularity.

CORE CONCEPTS
01
STATE SET
Q
A finite, non-empty set of states Q = {q₀, q₁, ..., qₙ}. Each state represents a configuration of the machine at a given moment in processing.
02
ALPHABET
Σ
A finite set of input symbols. The machine reads one symbol at a time from left to right. Only symbols in Σ are valid input — all else is undefined.
03
TRANSITION FUNCTION
δ
Maps each state-symbol pair to a set of states. In an NFA, δ: Q × Σ → 2ᵐ. In a DFA, δ: Q × Σ → Q. The bridge between them is subset construction.
04
DEAD STATE
∅
The empty set ∅ is a trap — the DFA dead state. Once entered, no path leads to acceptance. All transitions from ∅ loop back to ∅. Rejection is certain.
05
ACCEPT STATES
F
F ⊆ Q. A DFA state built from a subset is accepting iff that subset contains at least one NFA accepting state. Acceptance is preserved across conversion.
06
ε-CLOSURE
ε
The set of all states reachable from a given state by following only ε-transitions. Computed recursively; foundational to correct NFA→DFA conversion.
